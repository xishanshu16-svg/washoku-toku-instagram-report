# もみだれ焼肉 獅子楼 様×PR調査

大阪市福島区福島1-2-14／食べログ店舗番号27119726の新規PR選定レポート。
`restaurant-marketing-proposal-site` の4タブPRモードを使用。
既存のうお家・燕楽など他店のレポートや標準スキルは変更していない。

## 構成

- 概要：店舗の確認情報・成功要因3つ・企画4本・撮影指示書・Action Plan。
- 昼PR：指定4名のうち2名を定性評価、2名は近い昼投稿の直接根拠不足で保留。
- 夜PR：指定4名を定性評価。4観点・順位理由・元投稿と反応・依頼時の確認事項。
- 近似事例：実在するリール10件、昼2件＋夜／夜用途8件。10万以上8件、未満2件は参考。

## 調査範囲（2026-10-19）

指定4名の公開プロフィール、投稿先頭12件ずつの本文（48）、リール一覧先頭15件ずつ（60）、詳細14ページ。
10近似事例＋2補助根拠＋2非選定カフェの詳細を確認した。動画全編は0件。
全投稿・全期間の網羅調査ではない。2025年の過去投稿も含む。
保存・共有・維持率・視聴者地域・実送客・PR費は取得不可。
再生数・フォロワーは公開の丸め表示。欠損はnull保持、再投稿数をコメントに使わない。
Instagram既存ログイン状態で公開ページに直接アクセス。おすすめフィード・閲覧履歴は利用しない。

店舗は食べログ・店舗公式・運営公式を照合。Instagramの食べログ記載リンクは利用不可。
貸切人数・駅徒歩・夜閉店時刻に媒体差があるため、店舗確認事項として明記。
ランチは掲載更新日2025/10/13、コース一覧は2026/08/06。撮影前に現行条件を再確認する。
過去の別店の価格・期間条件は引き継いでいない。
勝因は本文からの仮説、撮影指示書は次回企画の提案で、未視聴映像の観察記録ではない。

## 再生成

```sh
node reports/shishiro-fukushima-2026-10-19/build.mjs
node reports/shishiro-fukushima-2026-10-19/test.mjs
```

`data.mjs` は店舗・取得数値・選定・根拠、`plans.mjs` は企画・撮影、`shell.mjs` は4タブUI。
`public/index.html` はCSS/JS内蔵で単一ファイル閲覧可能。
`public/evidence.json` は公開情報の要約と企画データ。認証情報・非公開インサイト・個人の閲覧履歴は含まない。
