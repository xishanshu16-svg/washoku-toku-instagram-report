## 再生成・テスト

リポジトリルートから：

```sh
node reports/enraku-kyoto-two-stores-2026-10-11/build.mjs
node reports/enraku-kyoto-two-stores-2026-10-11/test.mjs
```

`data.mjs`：店舗・公開数値・近似事例・店舗別相性。
`coverage.mjs`：調査範囲・詳細確認ID・非選定理由。
`plans.mjs`：企画・撮影構成（次回提案）。
`shell.mjs`：7タブ・ハッシュ・キーボード操作・背景モーション。
`public/index.html`：CSS/JS内蔵、単一ファイルで表示可能。
`public/evidence.json`：公開情報のみの根拠・企画データ。ログイン情報や個人インサイトは含まない。
