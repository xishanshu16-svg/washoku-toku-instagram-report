# うお家 × 大阪インフルエンサー選定

対象：寿司・魚料理 うお家。指定15アカウント。分析期間2026-08-11〜2026-10-11。

## 成果物

- `public/index.html`：選定ランキング・海鮮近似事例・企画と撮影指示書
- `public/accounts/<username>/index.html`：各アカウントの確認範囲内TOP10、個別5項目分析
- `public/data/report.json`：150投稿の公開数値とキャプション訴求要約
- `public/data/coverage.json`：622件の一覧候補・取得方法・期間境界

主要候補：ともとも、まんぷく、オーサカサカバ。相性は定性評価であり、来店成果保証ではありません。

## 証拠と制約

Instagramの指定プロフィールとリールを通常閲覧。候補622件、10万再生以上の表示377件。掲載TOP150は投稿日時・キャプション・公開反応数を個別照合。数値は丸め表示を含み、後から変動します。いいね非公開・コメント未取得はnullです。

期間候補はリール一覧と開始境界から抽出。全622件の日付個別照合ではなく、未表示・削除・非公開や並び替えは検出できません。全150動画の全編・音声・冒頭・時系列は未確認。勝因はキャプションと公開数値に基づく仮説、秒数付き台本は次回撮影の提案です。宿泊・イベント・地域外投稿は飲食店送客の直接証拠としません。

21表紙は通常画面の投稿リンクに関連付いた画像を取得。残りは「表紙未取得」と明示し、無関係な代替画像を使用していません。アカウントHTMLに画像とCSSを埋め込んでおり単独で閲覧可能です。

対象店の営業時間・価格・席は現行食べログトップを採用。旧メニュー欄に現行トップと食い違う条件があったため、個別料理価格は未確認とし提案では実会計に差替え。参考投稿の価格はキャプション記載で、客単価の独立照合ではありません。

## 再生成と公開

`node reports/uoya-osaka-2026-10-11/build.mjs`

集計はスキル付属`score_posts.py`を使用。入力は投稿日照合済みTOP10。候補622件の中央値は日付個別照合済み中央値とは別の指標として明示。

`npx wrangler@4 deploy --config reports/uoya-osaka-2026-10-11/wrangler.jsonc`

新しいWorker名`uoya-osaka-influencer-report`。他店のサイト・既存URLを上書きしません。公開後は本番で15ルート、TOP件数、開閉、リンク、スマホ表示を確認します。

自動更新・依頼先へのDM・契約・広告配信は実施していません。
